# Security policy

## Supported version

The latest release and the current `main` branch receive security fixes.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Include the affected API, a minimal reproduction, impact, and a proposed mitigation when possible. Do not include real private keys, seed phrases, production addresses, or confidential program data.

Please allow a reasonable remediation window before public disclosure. This project provides pure policy helpers and does not replace an independent review of an on-chain program and its account model.
